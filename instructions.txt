ROLE
You are a senior product designer and principal frontend engineer. You have shipped award-winning SaaS dashboards (Linear, Stripe, Vercel, Notion level polish). Build a COMPLETE, WORKING, production-quality frontend for "Recruiter.AI: Intelligent Hiring Decision Support System". Do not give me a plan or wireframes only. Build it, run it, open it in the browser, test every page and fix every bug before you tell me you're done.

PROJECT CONTEXT
Recruiter.AI is an AI-powered web platform for HR professionals. It helps them screen CVs, build evidence-based candidate personas, match candidates to jobs, detect hiring risk, predict retention and workforce demand, optimize job offers, and send AI-drafted selection/rejection emails. The core principle: AI ASSISTS the recruiter, it never makes the final hiring decision. Human review and approval is always visible in the UX.

Target users: HR professionals and recruiters. Tone: trustworthy, intelligent, calm, premium.

TECH STACK (frontend)
- React 18 + Vite + JavaScript (or TypeScript if you prefer, but keep it clean)
- Tailwind CSS with a custom design-token config
- Framer Motion for all animations and page transitions
- React Router v6
- Recharts for charts, plus custom SVG for gauges and radar charts
- Lucide React for icons
- Zustand (or Context) for state
- React Hook Form + Zod for forms
- Sonner or react-hot-toast for toasts
- Axios, with a SERVICE LAYER that talks to a FastAPI backend at VITE_API_BASE_URL (REST + JWT). Every service function must fall back to realistic MOCK DATA when the backend is unreachable, so the app works fully standalone right now and can be wired to the real FastAPI backend later by flipping one env flag (VITE_USE_MOCK=true).
- Mock API calls must simulate latency (400–1200ms) so loading states and skeletons are visible.

DESIGN DIRECTION: "Modern, Professional, Elegant"
Create a distinctive look. Avoid generic template-looking UI.

1. Theme
- Ship BOTH Light and Dark mode with a smooth animated toggle, persisted in localStorage, and respecting prefers-color-scheme.
- Palette: deep midnight indigo (#0B1020 base for dark), a vibrant electric violet to indigo gradient as the primary brand (#6D5EF5 → #4F46E5), a fresh emerald accent for positive/verified (#10B981), amber for caution (#F59E0B), rose for risk (#F43F5E), and soft slate neutrals. Light mode uses warm off-white (#F7F8FC) with white cards.
- Define all colors as CSS variables / Tailwind tokens. No hard-coded hex in components.
- Use subtle glassmorphism on select surfaces (frosted cards, navbar, modals), soft layered shadows, 16–24px rounded corners, and thin 1px borders with low-opacity strokes.
- Add refined background details: a soft animated gradient mesh or aurora glow behind the hero, and a faint grid or noise texture on dashboards. Keep it elegant, not loud.

2. Typography (BIG and confident)
- Headings: "Sora" or "Plus Jakarta Sans" (Google Fonts). Body: "Inter". Mono for scores/IDs: "JetBrains Mono".
- Large, bold, editorial type scale:
  - Hero H1: clamp(3rem, 7vw, 5.5rem), weight 800, tight tracking (-0.03em), gradient text on key words
  - Page titles: 2.5–3rem, weight 700
  - Section headings: 1.75–2rem
  - Body: 1.0625–1.125rem with 1.7 line-height
  - Big KPI numbers: 3–4rem, tabular-nums, with animated count-up
  - Minimum UI text size 14px. Never tiny, cramped text.
- Generous whitespace and strong hierarchy. Every screen should have one clear focal point.

3. Animations and micro-interactions (use Framer Motion)
- Page transitions: fade + slight upward slide, with AnimatePresence between routes.
- Staggered entrance for cards, lists and table rows.
- Scroll-triggered reveal animations on the landing page (whileInView).
- Animated count-up on every KPI.
- Animated circular gauges and progress bars for match score, risk score, retention score (animate from 0 to value on mount).
- Charts animate on load.
- Hover effects: card lift + glow, button shine sweep, magnetic CTA buttons, icon nudges.
- Animated sidebar with collapse/expand and a sliding active-indicator pill (layoutId).
- Skeleton shimmer loaders for all async content, plus a skeleton-to-content crossfade.
- "AI thinking" animation for persona generation: a multi-step progress sequence (Parsing CV → Extracting skills → Checking GitHub → Checking LinkedIn → Verifying evidence → Building persona) with a typewriter / streaming text effect for the AI summary.
- Drag-and-drop CV upload zone with an animated dashed border and a success checkmark morph.
- Animated toasts, modal spring transitions, tab underline slide.
- Respect prefers-reduced-motion by disabling heavy motion.
- Keep animation smooth (60fps), purposeful, and never blocking.

4. UX quality bar
- Fully responsive: mobile (360px), tablet, laptop, large desktop. Sidebar becomes a bottom sheet / drawer on mobile.
- Accessible: WCAG AA contrast, visible focus rings, keyboard navigation, aria labels, semantic HTML.
- Every list/screen needs a designed Empty state, Loading (skeleton) state, and Error state.
- Command palette (Cmd/Ctrl+K) for quick navigation and search.
- Breadcrumbs, tooltips, and helpful inline hints explaining AI results.
